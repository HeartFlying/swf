## 技术亮点

### 1. 双模式自动切换
- 信息完整度评分≥90 分 → 轻量化模式
- 信息完整度评分<90 分 → 常规模式
- 自动跳过冗余 Skill，提升执行效率

### 2. 断点续跑机制
- 支持用户主动暂停
- 支持异常中断后恢复
- 从断点位置继续执行，不重复执行已完成的 Skill

### 3. 标准化输出
- 所有 Skill 产物遵循统一模板
- 元信息 + 主体内容的固定结构
- 产物唯一 ID 强关联

### 4. 用户交互体系
- 3 个标准化交互节点
- 3 类用户输入格式（选择/补充/修改）
- 格式不规范时仅提醒一次

### 5. 格式校验闭环
- 前置校验 + 后置校验
- 通用校验 + 专项校验
- 自动修复 + 重跑机制
