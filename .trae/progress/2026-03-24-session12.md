#### 3. 竞品识别框架统一

**3 大类竞品**：
- **直接竞品**：解决相同问题、面向相同用户群体的产品（至少 2-3 个）
- **间接竞品**：解决相同问题但方式不同，或面向相邻用户群体的产品（至少 1-2 个）
- **潜在竞品**：具备相关能力可能进入该市场的产品（1-2 个）

**识别维度**：
- 产品维度：解决相同问题、满足相同需求
- 用户维度：面向相同或相邻用户群体
- 场景维度：覆盖相同或相似使用场景
- 能力维度：具备相关能力可能进入该市场

#### 4. 功能对标框架统一

**功能覆盖度评估**：
- 使用固定枚举值：`完全覆盖` / `部分覆盖` / `未覆盖`
- 统计各竞品的功能覆盖率
- 覆盖率计算公式：覆盖率 = (完全覆盖数 + 0.5 × 部分覆盖数) / 功能总数 × 100%

**体验对比评估**：
- 易用性对比：`优于` / `相当` / `劣于` / `无法评估`
- 性能对比：`优于` / `相当` / `劣于` / `无法评估`
- 视觉设计对比：`优于` / `相当` / `劣于` / `无法评估`
- 交互体验对比：`优于` / `相当` / `劣于` / `无法评估`

#### 5. 竞争格局评估框架统一

**市场成熟度评估**：
- 市场阶段：`萌芽期` / `成长期` / `成熟期` / `衰退期`
- 竞争激烈度：`低` / `中` / `高`
- 差异化空间：`大` / `中` / `小`
- 进入壁垒：`低` / `中` / `高`

**竞争威胁评估**：
- 对每个竞品评估竞争威胁等级：`高` / `中` / `低`
- 汇总各威胁等级的竞品数量
- 识别主要威胁来源

**SWOT 分析**：
- 优势（Strengths）：与竞品相比的优势点
- 劣势（Weaknesses）：与竞品相比的劣势点
- 机会（Opportunities）：市场机会点
- 威胁（Threats）：市场威胁点

#### 6. 差异化分析框架统一

**市场空白点识别**：
- 识别未被满足的需求点
- 识别功能覆盖不足的领域
- 识别体验优化的机会点
- 评估每个空白点的机会价值：`高` / `中` / `低`
- 评估每个空白点的实现难度：`高` / `中` / `低`

**优先级评估标准**：
- **P0**：高机会价值 + 低实现难度，优先实施
- **P1**：高机会价值 + 中实现难度，或中机会价值 + 低实现难度
- **P2**：其他组合，暂缓实施

#### 7. 质量标准完善

- 可读性（权重 15%）：结构清晰，表达准确，易于理解
- 可追溯性（权重 10%）：关键结论可追溯到数据来源

**检查清单**：
- 完整性检查（7 项）

- 质量验收（4 项）

**质量综合得分** = 完整性×30% + 准确性×25% + 一致性×20% + 可读性×15% + 可追溯性×10%
