# SWF 快速启动指令

## 触发方式

当用户输入以下任意内容时触发：
- `/swf`
- `开始需求分析`
- `启动SWF`
- `需求分析工作流`

---

## 启动流程

### 步骤1：初始化检查

1. 检查 `database/` 目录是否存在，不存在则创建
2. 询问用户原始需求
3. 确认用户已准备好开始

### 步骤2：执行 Skill0 - Plan制定

**执行内容**:
1. 解析用户原始需求
2. 评估信息完整度（4维度评分）
   - 边界清晰度（25分）
   - 需求具体度（25分）
   - 约束明确度（25分）
   - 目标明确度（25分）
3. 生成 Plan ID（格式：P + 6位数字，如 P000001）
4. 确定执行模式：
   - 总分 ≥ 90分 → 轻量化模式
   - 总分 < 90分 → 常规模式
5. 创建目录：`database/{PlanID}/`
6. 生成产物：
   - `database/{PlanID}/00-plan.md`（Plan定义）
   - `database/{PlanID}/00-todo-list.md`（任务跟踪）

**用户交互**:
- 如信息完整度低于60分，触发信息补全提问
- 展示评分结果和执行模式，请求确认

### 步骤3：按阶段执行

根据执行模式，按顺序执行各Skill：

**常规模式执行序列**:
```
S0(Skill0) → S1(Skill1→Skill2→Skill3→Skill4) → S2(Skill9→Skill10) → S3(Skill7→Skill11→Skill12) → S4(Skill5→Skill6→Skill8→Skill15)
```

**轻量化模式执行序列**:
```
S0(Skill0) → S1(Skill1→Skill2→Skill4) → S3(Skill7→Skill11→Skill12) → S4(Skill5→Skill6→Skill8)
```
（跳过 Skill3、Skill9、Skill10、Skill15）

## Skill执行规范

### 通用执行流程

每个Skill按以下步骤执行：

1. **前置检查**
   - 检查输入产物是否存在
   - 检查前置Skill是否已完成
   - 读取相关上下文

2. **用户交互（如需要）**
   - 检测信息缺失/模糊
   - 触发定向提问
   - 记录交互内容

3. **执行核心分析**
   - 按Skill定义执行分析
   - 生成结构化内容

4. **生成产物**
   - 使用对应模板
   - 填充分析结果
   - 保存到 `database/{PlanID}/`

5. **用户评审**
   - 展示产物核心内容
   - 请求用户确认/修改
   - 记录评审结果

6. **更新状态**
   - 更新 `00-todo-list.md`
   - 记录执行进度

## 异常处理速查

| 场景 | 处理方式 | 用户提示 |
|------|----------|----------|
| 前置产物缺失 | 暂停，提示先完成前置Skill | "请先完成【SkillX】，当前产物缺失" |
| 信息不完整 | 触发交互，请求补充 | "需要补充：{字段}" |
| 用户长时间未响应 | 保存状态，暂停 | "已暂停，等待您的输入..." |
| 用户要求修改 | 根据意见调整 | "正在根据您的意见修改..." |
| 产物保存失败 | 检查目录权限后重试 | "保存失败，请检查目录权限" |
