# Prompt: 竞品分析 (Skill9)

## 触发条件

当需要执行 Skill9 - 竞品分析时使用（仅常规模式）。

## 提示词

```
请执行【Skill9 - 竞品分析】。

## 输入信息
- Plan ID: {PlanID}
- 需求验证报告: artifacts/{PlanID}/04-validation.md
- 产品目标: {目标}
- 目标用户: {用户}
- 核心场景: {场景}
- 功能需求: {功能列表}

## 执行步骤

1. **竞品识别**
   - 直接竞品：解决相同问题、面向相同用户的产品
   - 间接竞品：解决相同问题但方式不同的产品
   - 潜在竞品：可能进入该市场的产品

2. **竞品信息收集**（每个竞品）
   - 基本信息：名称、公司、定位、目标用户
   - 核心功能：功能清单、特点、亮点
   - 市场表现：用户规模、口碑、定价

3. **功能对标分析**
   - 功能覆盖度：完全覆盖/部分覆盖/未覆盖
   - 体验对比：易用性、性能、视觉、交互

4. **竞争格局评估**
   - 市场阶段：萌芽期/成长期/成熟期/衰退期
   - 竞争激烈度：低/中/高
   - SWOT分析

5. **差异化分析**
   - 市场空白点识别
   - 差异化策略建议

## 输出要求

生成产物文件：artifacts/{PlanID}/09-competitor.md

使用模板：templates/all-templates.md 中的 Skill9 模板

## 特别说明

- 至少识别2-3个直接竞品
- 功能覆盖度使用固定枚举值
- 不确定信息要标注来源和可信度
- 结论必须有数据支撑
```

## 使用示例

```
/swf skill9 P000001
```

或

```
执行竞品分析，Plan ID: P000001
```

## 预期输出

产物文件 `artifacts/{PlanID}/09-competitor.md`，包含：
- 竞品清单（直接/间接/潜在）
- 功能对标矩阵
- 竞争格局评估
- SWOT分析
- 差异化策略建议

## 后置操作

1. 更新 `artifacts/{PlanID}/00-todo-list.md`
2. 执行 Skill10 - 市场痛点验证
