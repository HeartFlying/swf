# 执行详情

本 Skill 详细执行步骤参考 SKILL.md Section 3 流程概览。

---

## 详细执行步骤

### 步骤 1：前置校验

**输入验证**：
- 技术选型报告 (S302产物) 是否存在
- 需求验证报告 (S204产物) 是否存在
- Plan 定义文件是否完整

**异常处理**：
- 产物缺失 → 返回 E002，提示前置条件不满足
- 内容不完整 → 返回 E001，请求补充信息

### 步骤 2：读取技术选型结果

**读取内容**：
- 选定的技术栈
- 技术约束条件
- 架构风格决策

### 步骤 3：识别关键质量属性

**质量属性分类**：
| 类别 | 关键属性 |
|------|----------|
| **性能** | 响应时间、吞吐量、并发数、资源利用率 |
| **安全** | 认证、授权、加密、审计、合规 |
| **可用性** | SLA、RTO、RPO、维护窗口 |
| **可扩展性** | 水平扩展、垂直扩展、数据增长 |
| **可维护性** | 代码质量、文档、监控 |

### 步骤 4：用户交互 - NFR优先级确认

**交互方式**：使用 `option-selection-template.md`

**确认内容**：
- 质量属性优先级排序
- 关键指标目标值确认
- 约束条件确认

### 步骤 5：定义性能需求

**性能指标定义**：

| 指标 | 优秀 | 良好 | 一般 |
|------|------|------|------|
| 页面加载时间 | < 1s | < 3s | < 5s |
| API响应时间 | < 100ms | < 500ms | < 1s |
| 并发用户数 | > 10K | > 1K | > 100 |
| 吞吐量 | > 10K TPS | > 1K TPS | > 100 TPS |

### 步骤 6：定义安全需求

**安全需求维度**：
1. **认证授权**：身份验证方式、权限模型
2. **数据加密**：传输加密、存储加密、密钥管理
3. **审计日志**：操作记录、访问日志、合规要求
4. **安全合规**：行业标准、法规要求

### 步骤 7：定义可用性需求

**可用性指标**：

| 等级 | 可用性 | 年停机时间 |
|------|--------|-----------|
| 99.9% | 三个9 | 8.76小时 |
| 99.99% | 四个9 | 52.56分钟 |
| 99.999% | 五个9 | 5.26分钟 |

### 步骤 8：定义可扩展性需求

**扩展性维度**：
- 水平扩展能力
- 垂直扩展上限
- 数据增长预期
- 流量增长预期

### 步骤 9：定义其他NFR

**其他质量属性**：
- 兼容性需求（浏览器、设备、系统集成）
- 可维护性需求（代码质量、文档标准）
- 可观测性需求（监控、告警、追踪）

### 步骤 10：生成质量属性场景

**场景格式**：
```
场景名称：[场景描述]
刺激源：[触发源]
刺激：[具体刺激]
制品：[受影响的系统组件]
环境：[系统运行环境]
响应：[系统响应行为]
响应度量：[可量化的响应指标]
```

### 步骤 11：后置校验

**校验内容**：
- 所有质量属性已定义
- 指标可量化、可验证
- NFR之间无冲突
- 与功能需求一致

### 步骤 12：生成产物

**产物清单**：
1. 非功能需求规格书
2. 质量属性场景
3. 约束条件清单

### 步骤 13：用户评审

**评审内容**：
- NFR定义完整性
- 指标合理性
- 约束条件确认
