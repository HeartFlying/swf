# 附录 - 验收检查清单

## 非功能需求定义验收检查清单

### 完整性检查（30%）

- [ ] 性能需求已定义（响应时间、吞吐量、并发）
- [ ] 安全需求已定义（认证、授权、加密）
- [ ] 可用性需求已定义（SLA、RTO、RPO）
- [ ] 可扩展性需求已定义（容量、增长）
- [ ] 可维护性需求已定义（代码、文档）
- [ ] 兼容性需求已定义（浏览器、设备、集成）

### 可度量性检查（25%）

- [ ] 所有关键指标有明确的数值目标
- [ ] 指标可测试、可验证
- [ ] 指标有明确的测量方法
- [ ] 性能指标有基准参考

### 一致性检查（20%）

- [ ] NFR与功能需求一致
- [ ] NFR与技术选型兼容
- [ ] 各NFR之间无冲突
- [ ] 约束条件与技术栈匹配

### 可行性检查（15%）

- [ ] 性能指标在选定技术栈下可实现
- [ ] 安全要求符合行业实践
- [ ] 成本在预算范围内
- [ ] 时间表可实现

### 可追溯性检查（10%）

- [ ] 每项NFR有业务依据
- [ ] 与业务目标关联清晰
- [ ] 质量属性场景有明确来源

## NFR 指标参考

### 性能指标参考

| 指标 | 优秀 | 良好 | 一般 |
|------|------|------|------|
| 页面加载时间 | < 1s | < 3s | < 5s |
| API响应时间 | < 100ms | < 500ms | < 1s |
| 并发用户数 | > 10K | > 1K | > 100 |
| 吞吐量 | > 10K TPS | > 1K TPS | > 100 TPS |

### 可用性指标参考

| 等级 | 可用性 | 年停机时间 | 适用场景 |
|------|--------|-----------|----------|
| 99.9% | 三个9 | 8.76小时 | 一般业务系统 |
| 99.99% | 四个9 | 52.56分钟 | 关键业务系统 |
| 99.999% | 五个9 | 5.26分钟 | 金融、医疗等高可用系统 |

### 安全等级参考

| 等级 | 说明 | 典型要求 |
|------|------|----------|
| **L1 - 基础** | 基础防护 | 密码认证、HTTPS |
| **L2 - 标准** | 标准安全 | 多因素认证、审计日志 |
| **L3 - 增强** | 增强安全 | 数据加密、入侵检测 |
| **L4 - 高级** | 高级安全 | 零信任架构、安全审计 |
