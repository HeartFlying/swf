## 4. 接口规范定义

### 4.1 URL 规范

- **基础路径**：`/api/v1`
- **资源命名**：复数名词，小写字母
- **层级关系**：`/users/{id}/tasks`
- **查询参数**：`/tasks?status=active&sort=-created_at`
- **版本控制**：URL路径中包含版本号

**命名示例**：

| 资源 | URL格式 |
|------|---------|
| 用户 | `/api/v1/users` |
| 用户任务 | `/api/v1/users/{userId}/tasks` |
| 任务详情 | `/api/v1/tasks/{taskId}` |

### 4.2 HTTP 方法规范

| 方法 | 用途 | 幂等性 | 示例 |
|------|------|--------|------|
| GET | 获取资源 | 幂等 | `GET /api/v1/users/{id}` |
| POST | 创建资源 | 非幂等 | `POST /api/v1/users` |
| PUT | 全量更新 | 幂等 | `PUT /api/v1/users/{id}` |
| PATCH | 部分更新 | 非幂等 | `PATCH /api/v1/users/{id}` |
| DELETE | 删除资源 | 幂等 | `DELETE /api/v1/users/{id}` |

### 4.3 状态码规范

| 状态码 | 使用场景 | 说明 |
|--------|----------|------|
| 200 OK | 成功响应 | 标准成功 |
| 201 Created | 创建成功 | 返回新资源 |
| 204 No Content | 删除成功 | 无返回体 |
| 400 Bad Request | 请求参数错误 | 客户端错误 |
| 401 Unauthorized | 未认证 | 需要登录 |
| 403 Forbidden | 无权限 | 权限不足 |
| 404 Not Found | 资源不存在 | 路径或资源不存在 |
| 409 Conflict | 资源冲突 | 重复创建等 |
| 422 Unprocessable | 业务逻辑错误 | 验证失败 |
| 429 Too Many Requests | 限流 | 请求过于频繁 |
| 500 Internal Error | 服务器错误 | 服务端异常 |

### 4.4 请求/响应格式

**标准成功响应**：

```json
{
  "code": 200,
  "message": "success",
  "data": { },
  "timestamp": "2026-03-28T10:00:00Z",
  "request_id": "req_xxx"
}
```

**分页响应格式**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "items": [],
    "pagination": {
      "page": 1,
      "size": 20,
      "total": 100,
      "total_pages": 5,
      "has_next": true,
      "has_prev": false
    }
  }
}
```

**错误响应格式**：

```json
{
  "code": 400,
  "message": "请求参数错误",
  "errors": [
    {
      "field": "email",
      "message": "邮箱格式不正确",
      "code": "invalid_format"
    }
  ],
  "timestamp": "2026-03-28T10:00:00Z",
  "request_id": "req_xxx"
}
```

### 4.5 错误处理规范

**业务错误码设计**：

| 错误码范围 | 类型 | 示例 |
|------------|------|------|
| 400xxx | 参数错误 | 400001 - 参数缺失 |

| 403xxx | 权限错误 | 403001 - 无访问权限 |
