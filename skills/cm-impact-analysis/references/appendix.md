# 附录 - 验收检查清单

## 变更影响分析验收检查清单

### 变更类型判定检查

- [ ] 变更描述已完整解析
- [ ] 变更类型已正确判定（需求/架构/设计）
- [ ] 变更范围已明确界定

### 依赖分析检查

- [ ] 依赖图谱已正确加载
- [ ] 直接影响产物已全部识别
- [ ] 间接影响产物已追溯完整
- [ ] 级联深度已正确计算

### 影响范围检查

- [ ] 影响系数计算准确
- [ ] 重执行路径完整无遗漏
- [ ] Skill 序列顺序正确

### 增量建议检查

- [ ] 保留产物已正确标记
- [ ] 更新建议合理可行
- [ ] 重建范围准确

### 产物完整性检查

- [ ] 变更影响分析报告已生成
- [ ] 变更追溯矩阵已更新
- [ ] 重执行计划已生成

### 可追溯性检查

- [ ] 变更来源已记录
- [ ] 影响链路可追溯
- [ ] 执行状态已更新

---

## 常见问题处理

| 问题 | 处理方式 |
|------|----------|
| 变更类型模糊 | 请求用户明确变更类型 |
| 依赖关系缺失 | 基于产物内容推断依赖 |
| 影响范围无法确定 | 采用保守策略，扩大重执行范围 |
| 循环依赖检测 | 标记风险，建议人工介入 |
