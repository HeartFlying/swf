## 三、共性问题与改进建议

### 3.1 共性问题

1. **模板路径引用不一致**（S5-A02, S5-A03, S5-A05, S5-A06, S6-A02, S6-A03）
   - 问题描述：多个 Skill 的模板引用路径与实际目录结构不符
   - 影响范围：文档可维护性、AI IDE 正确加载模板
   - 建议：统一检查并修正所有模板引用路径为实际目录

2. **产物路径格式不统一**（S5-A01）
   - 问题描述：产物存储路径格式在不同 Skill 中存在细微差异
   - 影响范围：产物管理一致性
   - 建议：统一使用 `{PlanID}/{PlanID}-SKILL_ID-001.md` 格式

3. **Contract 与实际产物不一致**（S5-A06, S6-A03, S6-A04）
   - 问题描述：Contract 表格中的 Outputs 字段与实际产物清单不完全匹配
   - 影响范围：产物追溯、自动化处理
   - 建议：统一 Contract 字段与实际产物清单保持一致

4. **元信息与 Contract 表述不一致**（S5-A02, S6-A04）
   - 问题描述：元信息表格与 Contract 表格中相同字段的表述方式不同
   - 影响范围：文档一致性、可读性
   - 建议：统一表述方式，保持术语一致
