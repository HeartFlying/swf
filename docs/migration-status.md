## 单一事实源

**workflow-manifest.yaml** 是阶段和 Skill 定义的唯一事实源。

- 位置：`agents/workflow-manifest.yaml`
- 内容：阶段定义、Skill 定义、阶段交接、轻量化模式

所有 coordinator 和 SKILL.md 应引用此文件，而非重复定义。
